# Assets optimisés

Déposer ici la photo de profil sous le nom `photo.jpg` (ou `.png` / `.webp`).

Le composant `HeroId.astro` la détecte automatiquement au build :
Astro la redimensionne, la convertit en WebP et génère les bons attributs
`width` / `height`. Aucune ligne de code à modifier.

Tant qu'aucun fichier n'est présent, le cadre affiche le placeholder
silhouette + ligne de scan.

Format conseillé : carré, 800×800 minimum, cadrage buste.
